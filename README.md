# Global Power Plant Exploratory Data Analysis (EDA)

## Project Overview
This repository contains a comprehensive exploratory data analysis of the Global Power Plant Database dataset using Python, Pandas, Seaborn, and Matplotlib.

## Dataset
- **Source:** Kaggle (Global Power Plant Database)
- **Features:** 7 numerical features and 9 categorical features tracking power plant capacity, primary fuel types, commissioning years, and geographical locations.

## Key Insights
- Analyzed power plant density vs. cumulative capacity across top energy-producing nations.
- Investigated distribution patterns across renewable vs. non-renewable fuel sources.
- Examined historical commissioning trends from 1900 to 2018.
